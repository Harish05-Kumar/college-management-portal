# College Placement Management System

A full-stack web application developed to streamline and manage the college placement process through dedicated Student and Admin portals.

## Key Features

### Student Portal

- Secure registration and JWT-based authentication
- Student profile and profile photo management
- Resume upload, preview, download, and Resume Builder
- Campus placement drive browsing and applications
- External job search
- Application status tracking
- Email notifications for application updates

### Admin Portal

- Placement management dashboard
- Student and company management
- Campus drive creation and management
- Student application review and status management
- Student resume and application history
- Email notifications for application status updates

## Technology Stack

**Frontend:** React.js, JavaScript, HTML5, CSS3
**Backend:** Java, Spring Boot, Spring Security, REST APIs, JWT
**Database:** MySQL
**Tools:** IntelliJ IDEA, MySQL Workbench, Postman, Git, GitHub

## Security

- JWT-based authentication and authorization
- BCrypt password encryption
- Role-based access control
- Protected REST APIs

## Objective

To provide a centralized platform for managing student profiles, resumes, placement drives, applications, and communication, while improving the efficiency and transparency of the college recruitment process.
